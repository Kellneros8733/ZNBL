# Za nás bylo líp

Point and click adventura ve stylu Henryho Stickmina se sketchovou kresbou. Hlavní hrdina je zabržděný důchodce Pepa Panděro, kterému dojdou léky.

**Hrát:** h[ttps://Kellneros8733.github.io/za-nas-bylo-lip/](https://kellneros8733.github.io/ZNBL/)

## Ovládání
- **Myš / dotyk:** klik na podlahu = chůze, klik na předmět = akce.
- **Inventář:** klávesa `I` nebo klik na „inventář“. Předměty se kombinují přetažením jednoho na druhý (nebo klik na jeden a pak na druhý).
- **Menu a ukládání:** klávesa `Esc` (4 pozice + autosave, ukládá se v prohlížeči).
- **Nápověda (Stará dobrá):** držet pravé tlačítko myši nebo klávesu `H`.

## Tří obtížnosti: Jsou realizovány volbou Vyber dobu:
- **Stará dobrá:** nápověda kolečky, bez ukazatelů léků a třesu.
- **Doba kamenná:** nápověda kolečky, bez ukazatelů léků a třesu, možnost přeskočení miniher.
- **Mladá divná:** bez nápovědy, s ukazatelem léků a třesu.

## Upozornění na obsah
Hra obsahuje černý humor, alkohol, drogy a postavu s xenofobními názory, které jsou předmětem satiry. Doporučeno od 16 let.

## Vývoj
Celá hra je jeden soubor `index.html` (canvas + JavaScript, bez knihoven). Lokálně ji otevři přes rozšíření Live Server ve VS Code.
